# 📦 Form Pengajuan Barang

Sistem Form Pengajuan Barang berbasis web yang dirancang untuk mempermudah proses permintaan, persetujuan, dan pencatatan kebutuhan barang dalam lingkungan perusahaan, gudang, sekolah, maupun organisasi.

## 🚀 Fitur Utama

- ✅ Form pengajuan barang yang mudah digunakan
- ✅ Validasi data input
- ✅ Tampilan modern dan responsif
- ✅ Pengelolaan data pengajuan secara terstruktur
- ✅ Mendukung penggunaan di desktop maupun perangkat mobile
- ✅ Mudah dikembangkan sesuai kebutuhan organisasi

## ⚙️ Instalasi

Clone repository:

```bash
git clone https://github.com/zaptha/Form_Pengajuan_Barang.git
```

Masuk ke folder project:

```bash
cd Form_Pengajuan_Barang
```

Buka file:

```text
index.html
```

menggunakan browser favorit Anda.

## 🎯 Use Case

Aplikasi ini dapat digunakan untuk:

- Pengajuan ATK (Alat Tulis Kantor)
- Pengajuan barang gudang
- Permintaan peralatan kerja
- Pengajuan inventaris
- Kebutuhan logistik internal

## 🔒 Keamanan

- Validasi input pada sisi klien (client-side validation)
- Disarankan menambahkan autentikasi jika digunakan pada lingkungan produksi
- Jangan menyimpan data sensitif pada sisi frontend tanpa proteksi tambahan
